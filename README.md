## معرفی

- این پروژه حاوی فایل‌های HTML، CSS و JavaScript لازم برای راه‌اندازی یک سایت شخصی ساده است.  
- طراحی ریسپانسیو و مینیمال است تا بتوانید به‌راحتی آن را مطابق سلیقهٔ خود تغییر دهید.  
- از GitHub Pages برای میزبانی و Cloudflare برای اختصاصی‌سازی دامنه و فعال‌سازی CDN/SSL استفاده شده است.

## شروع سریع

1. مخزن را کلون کنید:
   ```bash
   git clone https://github.com/m-hamza/personal-site.git
   cd personal-site
   ```
2. تغییرات دلخواه خود را اعمال کنید:
   - فایل‌های HTML را برای محتوا  
   - `assets/css/` برای استایل  
   - `assets/js/` برای اسکریپت  
3. تغییرات را کامیت و پوش کنید:
   ```bash
   git add .
   git commit -m "Customize for my own site"
   git push origin main
   ```

## سفارشی‌سازی دامنه

اگر دامنهٔ اختصاصی دارید (مثلاً `m-hamza.ir`):

1. وارد تنظیمات مخزن روی GitHub شوید:  
   **Settings → Pages → Custom domain**  
2. نام دامنهٔ خود (`m-hamza.ir`) را وارد و ذخیره کنید.  
3. فایل `CNAME` در ریشهٔ پروژه به‌صورت خودکار ایجاد می‌شود.

در نهایت آدرس سایت شما به‌شکل زیر درخواهد آمد:
- https://m-hamza.github.io/personal-site/  
- https://m-hamza.ir/

## ساخت و استقرار

این پروژه بدون نیاز به کامپایل یا ابزار اضافی اجرا می‌شود.  
1. اطمینان حاصل کنید که شاخهٔ `main` به GitHub Pages متصل باشد.  
2. در بخش **Settings → Pages** شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید.  
3. چند دقیقه صبر کنید تا سایت شما در دسترس قرار گیرد.

## پیکربندی Cloudflare

برای استفاده از CDN و HTTPS رایگان:

1. یک اکانت در [Cloudflare](https://www.cloudflare.com/) بسازید.  
2. دامنهٔ `m-hamza.ir` را افزود‌ه و NSهای ارائه‌شده را در پنل رجیسترار تنظیم کنید.  
3. در داشبورد Cloudflare به تب **DNS** بروید و رکوردهای زیر را اضافه کنید:
   - **A** → Name: `@` → Content: `185.199.108.153` (و سه آدرس دیگر GitHub Pages)  
   - **CNAME** → Name: `www` → Content: `m-hamza.github.io`  
   - (اختیاری) **AAAA** برای IPv6  
4. Proxy (ابری نارنجی) را فعال کنید تا CDN و SSL فعال شود.
