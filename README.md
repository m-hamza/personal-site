# personal-site
سایت شخصی محمد حمزه

این پروژه مربوط به کدهای سایت بنده هستش که اگر تمایل داشتید میتونید کپی از این پروژه بگیرید و برای خودتون سایت اختصاصی ایجاد کنید.
 همچنین میتونید از بخش تنظیمات بخش پیجیز دامنه اختصاصی برای پروژتون تعریف بکنید مثل سایت خودم که همزمان کلود فلییر و گیت هاب استفاده کردم.
